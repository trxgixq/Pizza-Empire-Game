If your Mac asks “Are you sure you want to open it?”

Your Mac may display a security message because Pizza Empire was downloaded from the internet.

If the message asks whether you are sure you want to open the app:

Click Open to continue, provided you trust the source of the download.

If the message says Apple cannot check the app for malicious software, or that the developer cannot be verified:

Try opening Pizza Empire once, then close the warning.

Open System Settings on your Mac.

Select Privacy & Security.

Scroll down to the Security section.

Find the message about Pizza Empire and click Open Anyway, if that option is available.

Confirm your choice when the warning appears again.

You should then be able to open the game normally.
